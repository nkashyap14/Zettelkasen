# Chapter 3 Decision Tree Learning

## General Details

- Decision Tree Learning is one of the most widely used and practical methods for [[inductive inference]]
- Decision tree learning is a method for approximating [[discrete-valued target functions]] in which the learned function is represented by a [[decision tree]]
- Learned tree's can also be represented as sets of if-then rules to improve human readability
- Is one of the most popular of inductive inference algorithms
