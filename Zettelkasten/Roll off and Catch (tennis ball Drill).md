# Roll off and Catch (tennis ball Drill)

## Goal of Drill

- Improve eye hand coordination + hand speed + focus
## Textual Description

- Set arm at an angle
- Put tennis ball with other hand on the wrist
- Let it roll off and then bring arm around and catch the tennis ball
