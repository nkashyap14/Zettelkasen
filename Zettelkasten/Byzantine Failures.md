# Byzantine Failures

- A type of a failure in a [[Distributed System]] where the node exhibits random behavior like transmitting arbitrary messages at arbitrary times, producing wrong results, or stopping midway
- Can be due to an attack by a malicious entity or a software bug
- Most challenging type of failure to deal with
