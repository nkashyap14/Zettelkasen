# Appropriate Problems for Decision Tree Learning

- Best suited to problems like:
	- Where instances are represented by attribute value pairs
		- Fixed set of attributes (temperature etc)
		- Values (hot etc)
		- Best when takes on a small number of dijoint possible values though can handle real valued attributes as well
	- Target function has discrete output values
		- Ie yes or no
		- Or more than two possible values
		- Extension for real valued outputs though application of decision trees is less common
	- Disjunctive expressions (or) are required
	- Training data may contain errors
		- Decision trees are robust to errors
		- Both in classification of training examples and errors in attribute values
	- Training data may contain missing values
- Concrete examples of practical problems:
	- Classify medical patients by disease
	- Equipment malfunctions by their cause
	- Loan applicants to likelihood of default
	- Tend to be referred to as [[classification problems]]
