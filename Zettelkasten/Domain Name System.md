# Domain Name System

- DNS (Domain Name System) is a protocol which arose due to the fact that humans can't easily remember the mapping of domain names to [[IP addresses]] which are how we would visit a specific computer.
	- An IP address is a unique identifier for a computer
		- It is a logical address so it can change on a network
	- DNS functions as a phone book mapping of domain names to ip addresses
- Domain name system is the Internet's naming service which maps human-friendly domain names to machine-readable IP addresses
