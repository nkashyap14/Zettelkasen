# Run in and Out

## Goal of Drill

- Increase ability to move feet rapidly while also shifting along both x and y axis
## Textual Description

- Start with two feet set outside the band
- Run both in to the band
- Then send left leg left outside band and right leg outside band right
- Then run back into the band
- And run back out of the band to same starting position
- Repeat
